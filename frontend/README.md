# ERP System Frontend

React.js Single Page Application built with Vite for Manufacturing & Supply ERP.

## Features
- Protected routes & AuthContext state management
- Dynamic Role-based UI rendering (`ADMIN` vs `SALES_USER`)
- Customer Enquiry creation with dynamic multi-product input
- Price Quotation generator with real-time discount/tax calculator
- Sales Order details view with live Inventory Availability Breakdown
- Stock reservation and Dispatch workflow triggers for Admin
